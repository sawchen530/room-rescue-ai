# Native image sources

Forest + gold house mark, same geometry as the web favicon. Generated by `native/scripts/generate_placeholders.py` (supersampled strokes, radial forest fill, gold sill). Good enough to open Xcode / Android Studio and to drop a 512×512 into Play Console. **Not commissioned brand art** — replace if you want a designer’s version.

| File | Size | Use |
| --- | --- | --- |
| `icon.png` | 1024×1024 | App icon source (no rounded-rect mask baked in) |
| `icon-foreground.png` | 1024×1024 | Android adaptive foreground (house only, safe-zone inset) |
| `icon-background.png` | 1024×1024 | Android adaptive background (forest + gold bar) |
| `splash.png` | 2732×2732 | Launch screen (mark on a rounded forest tile) |
| `splash-dark.png` | 2732×2732 | Dark launch screen (deeper forest, same mark) |

Play listing copies of the same mark live in `docs/store-assets/play-icon-512.png` and `play-feature-1024x500.png`.

## Replace before store submission

1. Drop a final **1024×1024** icon (and **2732×2732** splash, optional dark splash) in this folder, keeping the filenames above.
2. From `native/`: `npm install` then `npm run assets`.
3. Open the iOS and Android projects and confirm the icon is not blurry and sits inside each platform’s safe zone / mask.
4. Commit the regenerated `ios/` and `android/` mipmaps / `AppIcon` / splash images.

If you only change the Python generator:

```bash
python3 -m pip install pillow
python3 native/scripts/generate_placeholders.py
cd native && npm run assets
```

`npm run assets` is what copies these sources into `native/ios/` and `native/android/`. Editing `native/assets/` alone does not update the compiled app icon until that command runs.
